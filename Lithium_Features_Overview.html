1. System Architecture Overview

Lithium is an enterprise-grade Autonomous Operations Intelligence Platform engineered to detect, diagnose, and self-heal microservice outages in real time. It pairs a high-performance reactive client dashboard with a FastAPI orchestration engine, backed by durable SQLite 3 Write-Ahead Logging persistence and Google Gemini post-mortem intelligence.

Layer Technologies Core Responsibility
Frontend Engine Vanilla JS, Tailwind CSS, Lucide, HTML5 Canvas Reactive SRE dashboard, dynamic topology map, time-horizon scrubber, and live SSE stream.
Backend API Python 3.13, FastAPI, Uvicorn, asyncio Telemetry generation, chaos injection orchestrator, safety kill-switch, and REST API.
Storage Engine SQLite 3 with WAL Mode (Write-Ahead Logging) ACID persistence for active incidents, immutable audit ledgers, and post-incident reviews.
Machine Learning & AI Scikit-learn IsolationForest, Google Gemini 2.5 Multi-dimensional telemetry anomaly scoring & automated senior SRE PIR reports.

2. Implemented Features (Current Capabilities)

1. Real-Time System Health & KPIs Live

Header metrics for Overall Health (99.8%), Microservices Online (5/5), P99 Latency (32ms), and MTTR (16.2s) with live UTC clock and API connectivity status.

2. Microservice Dependency Topology Live

Interactive HTML5 Canvas directed graph (Clients ➔ Gateway ➔ Auth ➔ Payments ➔ SQLite DB) showing real-time health (Green/Red/Amber/Blue) with node hover & click drawer.

3. Chaos Injector & Outage Presets Live

Instant trigger buttons for Database Connection Deadlock, Auth Pod Memory Leak (OOM Kill), and Gateway DDoS Volumetric Surge with persistent SQLite logging.

4. Live Server Telemetry Controller Live

Interactive modal to inject custom telemetry: select failing service, scrub exact Calculated Risk Rate (1–100), adjust P99 latency, and test custom playbooks.

5. Dual Autonomy Modes Live

Hybrid Autonomous: AI diagnoses root cause and prepares fix, requiring human approval. Full Autonomous: 2.0s countdown zero-touch self-healing.

6. Safety Kill-Switch & Override Live

Manual override safety interlock in FastAPI backend that disarms AI auto-remediation, rejecting unauthorized modifications with HTTP 403 Forbidden.

7. Digital Twin Time Horizon Scrubber USP #1

Scrub forward into the future (0m to +30m) to inspect projected saturation cliffs up to 12 minutes in advance, with a one-click preemptive fix action.

8. Automated PIR Reports & PDF Export USP #2

AI post-mortem generation via Google Gemini with causal flow diagram (Root Cause ➔ Failure ➔ Remediation ➔ Recovery) and direct browser PDF download.

9. SQLite 3 WAL Persistence Live

Durable database storing all incident records, post-mortems, and an immutable audit ledger with JSON export support.

10. Machine Learning Anomaly Detection Live

Scikit-learn IsolationForest algorithm fitted to baseline telemetry, calculating real-time anomaly scores and confidence percentages.

11. Live Telemetry Streaming (SSE) Live

Server-Sent Events stream (/api/v1/telemetry/stream) broadcasting live metrics every 1.5s to an interactive terminal with category filters.

12. Single-Click Launch System Live

Automated start.bat and run_app.bat scripts that initialize the database, boot FastAPI on port 8000, start the web server on port 3000, and open the browser.

4. Team Quick Start Guide

  • Clone & Setup: All dependencies (FastAPI, Uvicorn, Scikit-learn, Google-GenAI) are already installed.
  • One-Click Launch: Double-click start.bat in the project root directory.
  • Backend API: Available at http://localhost:8000 (Swagger documentation at http://localhost:8000/docs).
  • Dashboard UI: Opens automatically at http://localhost:3000.
  • Database: Local SQLite WAL database file is located at backend/lithium.db.
